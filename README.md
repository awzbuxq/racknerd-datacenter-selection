## 逐个机房说清楚

### 洛杉矶 DC-02：唯一做过亚洲优化的节点，门槛是 2GB

DC-02 用的是 Multacom 机房，RackNerd 为这个节点单独做了 Asia Optimized 网络，接入中国电信、联通、网通，去程回程基本直连，不绕欧洲或日本。线路细节上，电信走 163 优化、联通走 AS4837，晚高峰的丢包表现比一般美西机房好一些，这也是它在国内圈子里口碑最稳的原因。

2GB 门槛不是传说。RackNerd 的促销公告里写得很直接：DC-02 只对 2GB 及以上的方案开放。所以 1GB 用户在下拉框里找不到它，不是缺货，是压根没开放。

延迟方面，多个第三方测评给出的数字并不统一，有说 150–180ms 的，有说 190–200ms 的，也有说 160ms 左右的。这些差异来自测试时间、运营商和具体节点，把它当成 150–200ms 的参考区间就行，别拿某一个数字当标准。

IP 质量有两种相反的说法。一种认为 DC-02 的 IP 相对干净，部分 IP 段还能解锁主流流媒体；另一种提醒这个机房用量大，部分 IP 的历史使用记录比较复杂，风险偏高。两边都有道理，稳妥做法是开通后先查一下分到的 IP，别急着迁数据。

测试 IP：`204.13.154.3`。官方每个机房都有 Looking Glass 页面，支持 ping、traceroute 和 MTR，晚高峰跑一遍比看任何测评都准。

### 圣何塞：1GB 档里最稳的西海岸选择

只打算花 $11.29 的话，圣何塞是这一档里最合理的选择。它同样在西海岸，三网往返基本直连，电信去程直连圣何塞，联通走 AS4837，联通用户的实际体感往往比电信还好一点。

它和 DC-02 的差距在网络优化程度上：DC-02 是专门定制的亚洲优化线路，圣何塞的优化程度略逊，但胜在 1GB 小机器也能选，库存也相对充足。多个测评给圣何塞的国内延迟在 160–180ms，和 DC-02 的区间有重叠。

移动用户要多一步：圣何塞对移动的延迟偏高，个别节点存在绕路。纯移动宽带的话，先 ping 测试 IP 再决定。

测试 IP：`192.210.207.88`。

### 洛杉矶 DC-03：要原生 IP 和 25 端口才选它

DC-03 和 DC-02 不是同一个物理机房。它在洛杉矶市中心的另一处设施，网络接的是 Cogent 一类运营商，提供美国原生 IP，开放 25 端口，三网往返也基本直连，但整体优化程度不如 DC-02。

所以它的价值不在速度，在用途：要发邮件、要美国原生 IP、或者赶上 DC-02 缺货，DC-03 才是答案。纯粹为了国内访问速度，它排在 DC-02 和圣何塞后面。

它的定位就是备选。圣何塞没货、或者你想多买一台对比，再考虑它。

## 下单前需要确认的五件事

**库存按机房独立计算。** 同一个套餐，洛杉矶缺货不代表圣何塞没货。蹲 DC-02 的正确动作是隔几天刷一次下单页，看洛杉矶下面有没有出现 DC-02，而不是等邮件通知。

**DC-02 断货是常态。** 每次大促（新年、黑五、双十一）会把 DC-02 重新放出来，通常几天内被抢空。真想要就上 2GB 或 3.5GB 档，赶到促销期别犹豫。

**72 小时内可以免费换 IP。** 如果分到的 IP 被墙，购买后 72 小时内提交工单可以免费更换，超过这个时间换 IP 要付 $3。所以拿到机器第一件事是测 IP，确认没问题再迁数据。

**促销套餐不能直接换机房。** 用了一阵子觉得机房不合适，没有一键迁移的选项。实际流程是备份数据、重新买一台目标机房的套餐、用 scp 或 rsync 迁移、改域名解析，旧的那台到期不续费。

**内存别压到 1GB 以下。** 768MB 的配置日常跑起来偏紧，1GB 是底线。建站建议 2GB 双核起步，跑数据库、编译或者多个服务并发，4GB 以上更稳。
